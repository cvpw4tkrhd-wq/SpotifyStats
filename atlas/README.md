# Listening Atlas

Drop in the data export you can request from Spotify and explore your listening: monthly and yearly reports, top artists and tracks,
taste and mood over time, a year-in-review story, decades, a world map of where your artists come from, and listening habits.

**Everything runs in your browser.** Your file is never uploaded. Results are stored in your browser (IndexedDB) and can be deleted from the menu.

## Use it
1. Request **Extended streaming history** at <https://www.spotify.com/account/privacy/> (Spotify can take up to 30 days). "Account data" also works, but covers only the last year and has fewer details.
2. Open the app and drop the `.zip` (or the `.json` files) onto the page.
3. Genres, moods, photos, covers, release years and artist countries are fetched gradually in the background.

## How it works
- `worker.js` reads the zip in a web worker (`vendor/fflate.js`), keeps only music listening and stores it locally (`store.js`).
- `core.js` is the analysis. It is deterministic: the same listening gives the same numbers regardless of file order.
- `enrich.js` looks up artist and album names at Last.fm (genres), Deezer (photos, covers, release years) and MusicBrainz (countries), with a local cache.
- `index.html` is the dashboard. `demo/` holds fictional data, generated by `tools/make-demo.js`.

## Publish your own copy
Fork the repo, enable GitHub Pages (Settings, Pages, deploy from branch `main`, folder `/`), and put your own free Last.fm API key in `config.js`
(<https://www.last.fm/api/account/create>). The key is visible to everyone who opens the page.
